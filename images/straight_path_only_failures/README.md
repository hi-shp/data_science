# 직선 구간만 추종한 비교 실험

기존 `main_light`의 GAP 중심점과 목적지까지 경로를 직선 구간으로 잇고 Pure Pursuit로 따라간 임시 실험입니다. 선박 물리, 장애물 배치, GAP 중심점 선택, 기본 조향 이득·필터와 PWM은 그대로 사용했습니다. 장애물 반발 조향과 MainSafetyGuard의 조향 개입은 직선·Bézier 두 대조군에서 동일하게 끄고, 경로 형상 차이만 비교했습니다. LiDAR는 기존 속도 조절에 계속 쓰입니다.

모두 실제 1x GUI에서 시작부터 충돌까지 이어진 녹화입니다. 화면의 청록색 1차·주황색 2차 선이 연속된 직선 구간이며, 선박은 이 경로만 추종합니다. 원본 녹화와 최적화본은 같은 프레임입니다. 기존 `main_light` 브랜치 코드는 수정하지 않았습니다.

발표 설명: 직선 구간의 목표 방향이 꺾일 때 선박은 질량과 유한한 회전 응답 때문에 즉시 새 방향으로 정렬되지 않습니다. Bézier 경로는 선회 구간을 연속적으로 표현하고 장애물 주변에서 곡률을 조정할 수 있습니다. 이 실험에서 다섯 시드는 직선 구간 추종 중 충돌했고 같은 개입 제외 조건의 Bézier 추종은 완주했습니다.

해석 한계: 곡선 경로의 장애물 주변 곡률 보정도 결과에 포함됩니다. 따라서 충돌의 원인을 질량·회전관성 하나로 단정하거나, 이를 기본 `main_light` 주행 성능으로 설명하면 안 됩니다.
