# MAIN LIGHT 중심점 직선 경로 비교 실험

기존 `main_light`의 동일한 GAP 중심점과 목적지, Pure Pursuit, 조향기, 안전장치, 장애물 배치, 선박 물리를 사용했습니다. 임시 실행에서 경로 생성 함수만 선박 위치와 해당 목표점 사이의 직선 90개 점으로 교체했습니다. 기존 브랜치 코드는 수정하지 않았습니다.

모두 GUI의 1x에서 처음부터 충돌까지 연속 녹화했습니다. 정지된 마지막 화면은 충돌 위치이며, 성공 장면을 이어 붙이지 않았습니다. Bézier 기준 결과는 동일 시드의 별도 결정론적 실행으로 확인했습니다.

해석: 직선 구간으로만 추종점을 만들면 선회가 필요한 지점에서 선박의 속도와 유한한 yaw 응답 때문에 목표 방향이 즉시 바뀌지 않아 장애물과 접촉할 수 있습니다. 다만 원래 Bézier 생성은 장애물 주변에서 곡률도 조정하므로, 이 다섯 비교만으로 충돌 원인을 질량·회전관성 하나로 단정하지 않습니다.

화면 위쪽의 청록색·주황색 선은 임시 직선 경로입니다. LiDAR hit/range와 후보 GAP은 숨겼지만 1차/2차 경로와 중심점 표시는 유지하여 비교 조건을 볼 수 있게 했습니다.
